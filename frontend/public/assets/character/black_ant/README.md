# 블랙앤트 캐릭터 에셋

파일 이름이 곧 라벨이다. 무엇을 들고 무슨 표정인지 열어 보지 않아도 고를 수 있어야
같은 자리에 같은 포즈가 두 번 들어가지 않는다. 이름은 `antenna-character-<색>-<장면>` 으로 짓는다.

| 파일 | 장면 | 쓰는 자리 |
| --- | --- | --- |
| `antenna-character-black.png` | 기본 정면 | 기본 마스코트 |
| `antenna-character-black-run.png` | 달리는 옆모습 | 진행·로딩 |
| `antenna-character-black-point.png` | 왼손으로 가리키며 웃음 | 안내·튜토리얼 |
| `antenna-character-black-chicken.png` | 윙크하며 치킨 한 입, 블록 더미에 앉음 | **이벤트 배너(예측하고 치킨 먹자)** |
| `antenna-character-black-chip-gift.png` | 베팅 칩 + 선물 상자 | 배팅·보상 안내 |
| `antenna-character-black-coins-ticket.png` | ANT 코인 더미 + 예측 티켓, 윙크 | 배팅 금액·적중 보상 |
| `antenna-character-black-chart-coin.png` | 상승 차트판 + ANT 코인 들고 점프 | 예측 등록 유도 |
| `antenna-character-black-cheer-chart.png` | 주먹 쥐고 환호, 상승 차트 + 트로피 | 적중·성공 결과 |
| `antenna-character-black-trophy.png` | 트로피 + 금메달, 색종이 | 시즌 결과·랭킹 1위 |
| `antenna-character-black-chain-blocks.png` | 체인으로 이어진 블록 두 개를 들고 있음 | 온체인 검증·커밋 원장 |
| `antenna-character-black-desk-plan.png` | 책상에서 태블릿에 필기, PLAN 메모 | 리서치·백테스트 |
| `antenna-character-black-team-board.png` | 셋이 대시보드를 함께 봄 | 커뮤니티·리더보드 |
| `antenna-character-white-magnifier.png` | 흰 옷 버전, 돋보기를 든 탐색 포즈 | 종목 탐색·검색 빈 상태 |
| `antenna-profile.png` | 얼굴만 자른 원형 | 기본 프로필 사진 |

배경이 흰 판인 파일은 `antenna-character-black-chicken.png` 하나뿐이고 나머지는 투명 PNG 다.
