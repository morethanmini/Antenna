# 천하제일 단타대회 배너 — 원본 조각

이벤트 배너(J-01 · 인사이트 홈)를 만든 **레이어 원본**이다. 디자인 시안을 겹으로
쪼갠 것이고, **화면이 직접 쓰는 파일은 아니다.**

화면이 쓰는 것은 `assets/event/*.webp` 다. **이름이 1:1로 같다** — `bg.png` 를
구운 것이 `bg.webp` 다. 잘라 내고(투명 여백 제거) 폭을 줄인 결과라, 합계 11MB 가
588KB 로 줄어 있다.

## 왜 완성본 한 장이 아니라 조각인가

처음엔 완성본 한 장을 받아 썼다. 그런데 그 그림이 **4.69:1** 이고 홈의 배너 자리는
그보다 한참 길고 낮아서, 세로로 자르면 제목도 캐릭터도 남지 않고 비율대로 넣으면
홈이 통째로 밀렸다.

조각으로 받으면 우리 비율(**9:1**)에 맞춰 다시 배치할 수 있다. 배경·차트·색종이는
추상 무늬라 늘리거나 잘라도 티가 안 나고, 제목·캡슐·캐릭터만 비율을 지키면 된다.

## 대회 페이지 머리 (J-01)

홈 배너와 다른 자리다 — `/events/scalping` 맨 위 카드에 쓴다. 배경·캐릭터는 위
조각을 그대로 쓰고, 아래 여섯 장이 더 붙는다.

| 파일 | 무엇 |
| --- | --- |
| `hero-pill-event.png` | `이벤트` 금색 캡슐 |
| `hero-title.png` | `천하제일 단타대회` 두 줄 제목 |
| `hero-lede.png` | 한 줄 소개 |
| `hero-opens-at.png` | `등록 시작 ǀ 9월 18일 (금) 13:10` |
| `hero-rules-title.png` | `대회 규칙` |
| `hero-rules.png` | 규칙 네 줄 패널 |

**`hero-opens-at` 에는 날짜가 구워져 있다.** 시작 전에만 맞는 말이라 그 단계에서만
쓰고, 등록이 닫힌 뒤에는 글자로 그린다. 나머지 단계 그림이 생기면 그때 바꾼다.

**`hero-rules` 도 날짜가 구워져 있다.** 일정이 바뀌면 `contest.ts` 의 `RULES`(읽어
주는 기기용 글)와 이 그림이 어긋나므로 **둘 다** 고쳐야 한다.
왕관만 예외로 **제목 폭의 %** 다 — 제목이 바뀌어도 같은 글자 위에 얹혀야 해서다
(`title-main` 383px, `title-done` 333px 로 폭이 다르다).

## 단계를 더 만들 때

`src/event/contest.ts` 의 `BANNER` 는 `Partial` 이 아니라 `Record<Phase, …>` 다.
단계를 새로 만들면 캡슐·제목·문구 세 장도 같이 만들어야 하고, 안 만들면 컴파일이
막는다. 한동안 "결과 집계 중" 만 비어 있어 그 구간이 글자 배너로 떨어졌는데
(2026-09-16 에 캡슐을 받아 채웠다), 그런 구멍이 조용히 생기지 않게 하려는 것이다.

## 다시 구우려면

시안이 바뀌면 같은 규칙으로 다시 구우면 된다.

1. 알파 경계로 잘라 낸다(투명 여백 제거)
2. 폭을 줄인다 — 배경 1700, 제목·문구·차트·색종이 900~1000, 캐릭터 560,
   왕관·캡슐·스티커 340~380
3. WebP `q=0.9` 로 저장한다

제목·문구처럼 **글로가 넓게 번진 장은 알파 문턱을 70 쯤으로 올려야** 한다.
문턱이 낮으면 눈에 보이지도 않는 번짐까지 상자로 잡혀, 제목 상자가 캔버스 전체
(2172 중 2101)로 나온다.
