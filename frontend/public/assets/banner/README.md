# 천하제일 단타대회 배너 — 원본 조각

이벤트 배너(J-01 · 인사이트 홈)를 만든 **레이어 원본**이다. 디자인 시안을 겹으로
쪼갠 것이고, **화면이 직접 쓰는 파일은 아니다.**

화면이 쓰는 것은 `assets/event/*.webp` 다. 이 폴더의 PNG 를 잘라 내고(투명 여백
제거) 폭을 줄여 구운 것이라, 합계 11MB 가 588KB 로 줄어 있다.

## 왜 완성본 한 장이 아니라 조각인가

처음엔 완성본 한 장을 받아 썼다. 그런데 그 그림이 **4.69:1** 이고 홈의 배너 자리는
그보다 한참 길고 낮아서, 세로로 자르면 제목도 캐릭터도 남지 않고 비율대로 넣으면
홈이 통째로 밀렸다.

조각으로 받으면 우리 비율(**9:1**)에 맞춰 다시 배치할 수 있다. 배경·차트·색종이는
추상 무늬라 늘리거나 잘라도 티가 안 나고, 제목·캡슐·캐릭터만 비율을 지키면 된다.

## 없는 것

**"결과 집계 중"(등록 마감 ~ 결과 공개) 캡슐이 없다.** 지금 캡슐 셋으로는 그
구간에 맞는 말이 없어, 그동안은 글자로 된 배너가 대신 나온다. 캡슐 한 장이 더
생기면 `src/event/contest.ts` 의 `BANNER` 에 한 줄만 더하면 된다.

## 다시 구우려면

`assets/event/*.webp` 는 이 폴더의 PNG 에서 자동으로 뽑은 것이다. 시안이 바뀌면
같은 규칙으로 다시 구우면 된다 — 알파 경계로 잘라 내고, 폭을 줄이고, WebP(q=0.9)
로 저장한다. 제목·문구처럼 글로가 넓게 번진 장은 알파 문턱을 70 쯤으로 올려야
보이지 않는 번짐까지 상자로 잡히지 않는다.
