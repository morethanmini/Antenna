# 천하제일 단타대회 배너 — 원본 조각

이벤트 배너(J-01 · 인사이트 홈)를 만든 **레이어 원본**이다. 디자인 시안을 겹으로
쪼갠 것이고, **화면이 직접 쓰는 파일은 아니다.**

화면이 쓰는 것은 `assets/event/*.webp` 다. **이름이 1:1로 같다** — `bg.png` 를
구운 것이 `bg.webp` 다. 잘라 내고(투명 여백 제거) 폭을 줄인 결과라, 합계 11MB 가
588KB 로 줄어 있다.

**구운 파일은 아직 이 브랜치에 없다.** 배너를 화면에 붙이는 변경과 함께 들어온다.
여기 있는 것은 원본 조각뿐이다.

## 왜 완성본 한 장이 아니라 조각인가

처음엔 완성본 한 장을 받아 썼다. 그런데 그 그림이 **4.69:1** 이고 홈의 배너 자리는
그보다 한참 길고 낮아서, 세로로 자르면 제목도 캐릭터도 남지 않고 비율대로 넣으면
홈이 통째로 밀렸다.

조각으로 받으면 우리 비율(**9:1**)에 맞춰 다시 배치할 수 있다. 배경·차트·색종이는
추상 무늬라 늘리거나 잘라도 티가 안 나고, 제목·캡슐·캐릭터만 비율을 지키면 된다.

## 조각

**공통** — 어느 단계에서나 그대로 깔린다.

| 파일 | 무엇 |
| --- | --- |
| `bg.png` | 보라 띠 바탕 |
| `chart.png` | 오른쪽으로 올라가는 캔들 |
| `confetti.png` | 금색 리본 |
| `crown.png` | 제목 위 왕관 |
| `mascot.png` | 단타왕 마스코트 |
| `sticker.png` | "단타로 세상을 놀라게!" |

**단계별** — 바뀔 때 갈아끼우는 것은 이 셋뿐이다.

| 단계 | 캡슐 | 제목 | 문구 |
| --- | --- | --- | --- |
| 시작 전 | `pill-before.png` | `title-main.png` | `copy-before.png` |
| 대회 진행 중 | `pill-open.png` | `title-main.png` | `copy-before.png` |
| 대회 종료 | `pill-done.png` | `title-done.png` | `copy-done.png` |

자리 값은 `src/styles/home.css` 의 `.hm-ev-*` 가 띠 높이(`cqh`) 하나로 잰다.
왕관만 예외로 **제목 폭의 %** 다 — 제목이 바뀌어도 같은 글자 위에 얹혀야 해서다
(`title-main` 383px, `title-done` 333px 로 폭이 다르다).

## 없는 것

**"결과 집계 중"(등록 마감 ~ 결과 공개) 캡슐이 없다.** 지금 캡슐 셋으로는 그
구간에 맞는 말이 없어, 그동안은 글자로 된 배너가 대신 나온다. 캡슐 한 장이 더
생기면 `pill-judging.png` 로 넣고 `src/event/contest.ts` 의 `BANNER` 에 한 줄만
더하면 된다.

## 다시 구우려면

시안이 바뀌면 같은 규칙으로 다시 구우면 된다.

1. 알파 경계로 잘라 낸다(투명 여백 제거)
2. 폭을 줄인다 — 배경 1700, 제목·문구·차트·색종이 900~1000, 캐릭터 560,
   왕관·캡슐·스티커 340~380
3. WebP `q=0.9` 로 저장한다

제목·문구처럼 **글로가 넓게 번진 장은 알파 문턱을 70 쯤으로 올려야** 한다.
문턱이 낮으면 눈에 보이지도 않는 번짐까지 상자로 잡혀, 제목 상자가 캔버스 전체
(2172 중 2101)로 나온다.
